## What is this? 這是什麼

這個網頁是一個互動式的教學網頁，可以讓我們更了解半導體產業的基礎知識。
網頁涵蓋了2個部分：
Part 1. 半導體產業介紹
    - 半導體產業鏈
    - 電晶體的結構：MOSFET、FinFET、GAA
    - 角色介紹與分工
    - 晶圓的製程流程 

Part 2. 新員工介紹：物理博士，凝態物理模擬
    - 能力介紹 (Simulation, Data Analysis, Experiment & Collaboration)
    - 我可以貢獻什麼? (模擬與數據分析、相關儀器與工具的原理介紹)

- 更多細節與內容將在未來被更新...
